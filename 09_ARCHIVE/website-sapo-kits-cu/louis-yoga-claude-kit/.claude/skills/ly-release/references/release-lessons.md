# Bài học phát hành

Chưa có release live được thực hiện bằng bộ kit này. Sau mỗi release đã chạy, ghi ngắn: release ID/date, điều kiện shop, cách deploy đã xác minh, sự cố, smoke tests, rollback đã thử/chưa thử và thay đổi cần làm trong quy trình. Giữ ID sản phẩm/customer/credential ngoài tài liệu chia sẻ.
